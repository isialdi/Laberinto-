Mueve con el joystick de la izquierda y arrastra por la derecha para girar la cámara. Botones: naranja para chutar el balón o tirar a canasta, azul para saltar y verde para hablar, abrir armarios o tumbarte. En el ordenador: W A S D para moverte, arrastrar con el ratón para mirar, Espacio para dejar una marca, X para chutar o tirar a canasta, Z para saltar, F para la acción (hablar, abrir armarios, tumbarte en la cama), V para cambiar de vista y Q/E para girar.
